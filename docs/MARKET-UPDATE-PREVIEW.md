# 分类订阅更新预告

以下为开发候选能力，尚未发布；当前正式安装包版本不变。

- 自动协商紧凑二进制身份分块与可选无损压缩，兼容旧版身份分页。
- 同连接退订后保留有界目录缓存，重订复用；缓存不赋予订阅权限。
- 默认等待期限随协商结果调整，只以有效身份进展续期，并保留总上限。
- 初始缓存行情采用有界接收确认，降低弱网下立即退订的控制阻塞风险。
- 等待无损行情块握手完成后发送订阅，不改变现有分类、行情及历史查询接口。

发布后需升级安装包并重启客户端进程。不同版本自动协商，不要求客户准备本地
市场目录或手动启用传输开关。所有接纳结果仍以 `wait_applied()` 成功返回为准。
