# 可选数值还原模块（尚未发布）

这是独立安装包，不改变主 SDK 的纯 Python 安装方式。模块只将有界的数值编码
还原为原始字节，解压继续使用 SDK 已有依赖；不依赖服务端源码、系统压缩库或
CPython 原生扩展接口。平台 wheel 使用 `py3-none-<platform>` 标签，不是通用 wheel。

```bash
python -m build native
```

构建需要 C11 编译器，运行不需要编译器。仅从受信任的发布渠道安装对应平台的
wheel。开发阶段版本为 `0.1.0.dev0`，尚未正式发布，不宣称所有平台已经验收。

模块检查 ABI、字段类型布局和浮点环境；要求 IEEE-754 双精度及默认舍入模式。
每次还原最多处理 128 KiB 变换数据，输出最多 64 KiB、256 条行情；失败不返回
部分输出。原生栈缓冲为 64 KiB，调用方不得自行使用不适配的小线程栈。

此包不自行选择传输格式，也不读取外部配置或任意动态库路径。是否声明协议能力
由主 SDK 自检和后续可选协商决定。没有安装、加载失败或不支持时，原有协议不变。
